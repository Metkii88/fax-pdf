# Fax-PDF: приём и отправка факсов в PDF на Astra Linux 1.7 (HylaFAX)

Комплекс для работы с факсами в формате **PDF** на базе [HylaFAX](https://github.com/ifax/HylaFAX)
(форк ifax/HylaFAX) под **Astra Linux 1.7 «Генеральный»** (Debian 10 buster-совместимая).

Текущая версия: **v1.3.7** — графический интерфейс «Факсимильный аппарат», голосовые вызовы,
сворачивание в трей, всплывающие уведомления, сборка HylaFAX из вендорной копии (без интернета),
deb-пакет.

## Состав

| Файл | Назначение |
|---|---|
| `install-astra.sh` | Установка зависимостей и сборка HylaFAX **из вендорной копии** `vendor/hylafax` (без скачивания с github.com) |
| `vendor/hylafax/` | Зафиксированная копия исходников HylaFAX master (6.1-GIT, commit c6cac8d8) с патчами libtiff 4.x — офлайн-сборка |
| `sendfax.sh` | Отправка PDF-файла по факсу (`./sendfax.sh документ.pdf 74951234567`) |
| `recv-monitor.py` | Сервис мониторинга: принятые факсы конвертируются в PDF, раскладываются по папкам пользователей (папка сохранения настраивается GUI, по умолчанию — домашняя `/home/user`) |
| `voice-monitor.py` | Монитор голосовых вызовов: RING/VOICE CALL из syslog → очередь пропущенных для GUI, автоответ (AT-оффхук) при поддержке модема |
| `gui/faxpdf/` | Графический интерфейс (PyQt5): live-мониторинг входящих, отправка PDF, вкладка **«Факсимильный аппарат»**, трей, уведомления, диалог «О программе» |
| `debian/` | Правила сборки deb-пакета (`dpkg-buildpackage`) |
| `hylafax/*` | Шаблоны конфигурации HylaFAX (`config.local`, правила приёма/отправки, маршруты) |
| `systemd/*.service` | Юниты: hylafax (faxq+faxgetty), fax-xferfaxd, fax-pdf-monitor, fax-pdf-voice |
| `webapp/` | Лёгкий веб-интерфейс (Flask) для загрузки PDF в очередь и просмотра статуса |

## Быстрый старт (на Astra Linux 1.7, от root)

**Вариант 1 — установка готового deb-пакета (рекомендуется):**
```bash
wget https://github.com/Metkii88/fax-pdf/releases/download/v1.3.7/fax-pdf_1.3.7-1_all.deb
sudo apt install ./fax-pdf_1.3.7-1_all.deb
sudo apt install -y python3-pyqt5 libtiff-tools poppler-utils inotify-tools   # зависимости GUI/конвертации
```

**Вариант 2 — установка из исходников:**
```bash
# 1. Подготовка системы: зависимости + сборка HylaFAX из вендорной копии vendor/hylafax
#    (git clone с github.com НЕ выполняется; для сборки из свежего upstream:
#     USE_BUNDLED=0 sudo ./install-astra.sh)
sudo ./install-astra.sh

# 2. Настройка модема (автоопрос портов, генерация etc/config для ttyS0)
sudo faxaddmodem ttyS0

# 3. Наложение наших конфигов
sudo cp hylafax/config.local /var/spool/hylafax/etc/config.local
sudo cp hylafax/FAXRules.recv /var/spool/hylafax/etc/FAXRules

# 4. Запуск сервисов
sudo systemctl enable --now hylafax fax-xferfaxd fax-pdf-monitor

# 5. Отправить PDF
./sendfax.sh /path/to/документ.pdf +74951234567
```

## Как это работает

### Отправка (PDF → факс)
1. Оператор выбирает файл(ы) в GUI (кнопка **TX▲**, множественный выбор) или вызывает
   `sendfax.sh файл.pdf номер`.
2. Скрипт конвертирует PDF → TIFF G3/G4 (`pdftoppm` + `tiffcp`): HylaFAX умеет отправлять
   только растровые форматы; оригинальный PDF архивируется в `/var/spool/hylafax/archive/sent/`.
3. `sendfax` ставит задачу в очередь `faxq`; `faxgetty` через модем набирает номер,
   передаёт изображение (V.29/V.17/V.34).
4. После отправки скрипт `etc/notify` пишет отчёт в `/var/log/fax-pdf/report.log` и
   уведомляет оператора (письмо на localhost / всплывающее уведомление).

### Приём (факс → PDF)
1. `faxgetty` отвечает на звонок, принимает страницу, сохраняет в `recvq/` (TIFF-F).
2. `recv-monitor.py` (watchdog по inotify) ловит новые файлы, конвертирует TIFF→PDF
   (`tiff2pdf`), вычисляет SHA-256, складывает в папку сохранения (по умолчанию —
   домашняя папка пользователя `/home/user`, настраивается в GUI), формирует
   PDF-квитанцию и шлёт уведомление (в т.ч. всплывающее, даже если GUI свёрнут в трей).

## Требования к оборудованию
* Аналоговый модем Class 1 / Class 2.0 (Conexant, Lucent, USRobotics) — предпочтительно.
* **Поддерживаются также win-модемы Conexant HSF** (`/dev/ttySHSF*`) — см. раздел
  «Поддержка HSF-модемов» ниже: факс через HylaFAX, голос через утилиты драйвера vpmcall/vpmdrop.
* Порт RS-232 (`ttyS0`…`ttyS3`), USB-модем (`ttyUSB0`, `ttyACM0`) или PCI/AC97 HSF (`ttySHSF0`).
* GUI автоматически сканирует `/dev/ttyS*`, `/dev/ttyUSB*`, `/dev/ttyACM*`, `/dev/ttySHSF*`
  (sysfs/udev), помечает HSF-устройства и предлагает найденные в списке с драйвером и моделью;
  кнопка «Обновить» — пересканировать.
* Проверка: `dmesg | grep tty`, затем `chat -v "" ATZ OK "" AT+FCQ OK`
  (для HSF вместо chat — `hsftest` и `vpmstat`).

## Поддержка HSF-модемов (winmodem Conexant / Linuxant hsfmodem)
HSF-модемы не имеют полноценного AT-интерфейса: протокольную часть выполняет драйвер ядра.
Проект поддерживает их следующим образом:
* **Автоопределение**: `install-astra.sh` сканирует lspci/lsusb, при нахождении HSF ставит
  пакет `hsfmodem` (или подсказывает tar.gz Linuxant), выполняет `modprobe hsf`, прописывает
  модуль в `/etc/modules-load.d/fax-pdf-hsf.conf` и создаёт `/etc/hsfconf.d/99-fax-pdf.conf`
  (Voice-over-IP/VPM для голоса).
* **Факс**: HylaFAX работает с `ttySHSF*` через встроенный Class 1/2 эмулятор драйвера —
  после установки выполните `sudo faxaddmodem ttySHSF0`.
* **Голос**: GUI-аппарат определяет HSF по порту/драйверу (метка «· HSF» на плашке модема,
  кнопка **HSF** на корпусе открывает мастер: статус модуля, `/dev/vpmctl`, наличие vpmcall).
  Набор номера и подъём линии выполняются утилитами `vpmcall` (off-hook + DTMF) и `vpmdrop`
  (сброс); `voice-monitor.py` при автоответе на HSF-порту также использует `vpmcall` вместо
  AT-команд. Звук — через ALSA-конвейер драйвера (voip/ccmux).
* Ограничения: качество зависит от версии драйвера (Astra 1.7: `hsfmodem` из репозитория или
  Linuxant 3.10+); для голоса могут потребоваться root-права на `/dev/vpmctl` (правило udev
  `GROUP="dialout"`), это предлагается в мастере HSF.

## Структура каталогов после установки
```
/var/spool/hylafax/            — очередь HylaFAX (sendq, recvq, log, etc)
/srv/fax/incoming/<user>/      — принятые PDF (серверный режим)
/srv/fax/outbox/<user>/        — папка исходящих PDF оператора
/var/spool/hylafax/archive/    — архив отправленного/принятого
/opt/hylafax/                  — бинарники, собранные из ifax/HylaFAX
~/.config/fax-pdf/config.json  — настройки GUI (папка сохранения, модем, трей, автоответ)
```

## Графический интерфейс (v1.3.7)
```bash
# из исходников:
python3 -m faxpdf --demo        # демо-режим аппарата без модема (RING/RX/TX имитация)
fax-pdf-gui                     # после установки deb-пакета
fax-pdf-gui --minimized         # старт свёрнутым в трей
```
Устанавливается вместе с пакетом `fax-pdf_*.deb` (`sudo apt install ./fax-pdf_1.3.7-1_all.deb`).

Возможности GUI:
* **Факсимильный аппарат** — рисованный интерфейс факса: цифровая клавиатура (0–9, `*`, `#`,
  `+`, `C`, REDIAL), LCD-экран состояний READY/RING/RX/TX%/HOLD/ERROR/VOICE, лоток выдачи
  принятых документов (клик — открыть PDF), трубка, кнопки TX▲ / RX▼ / ■ СТОП / ⏸ HOLD / VOICE.
* **Выбор оборудования** — автоопределение модемов ttyS*/ttyUSB*/ttyACM* с выбором из списка.
* **Отправка** — множественный выбор файлов PDF/TIFF, прогресс постранично.
* **Приём** — live-мониторинг входящих, предпросмотр страниц, сохранение в выбранную папку
  (по умолчанию `/home/user`).
* **Голосовые вызовы** — режим VOICE, подъём/сброс «трубки», автоответ по числу колец.
* **Трей и фон** — сворачивание в системный трей (иконка факса), фоновый мониторинг,
  всплывающие уведомления о принятых/отправленных факсах и звонках, корректный «Выход» из меню трея.
* **Справка → О программе** — версия, описание возможностей, авторство.

### Сборка HylaFAX из вендорной копии (v1.3.2)
HylaFAX (ifax/HylaFAX master, commit c6cac8d8) включён в репозиторий как `vendor/hylafax/` —
при установке **не выполняется git clone** с github.com, работает на изолированных узлах.
К вендорной копии применены патчи совместимости с современными системами:
- `configure`: определение libtiff 4.x расширено до `4.[0-9]*` (`tiff_runlen_t=uint32`,
  `TIFFHeaderClassic`) — устраняет ошибки компиляции/линковки с libtiff5/6 и gcc-12;
- `debian/clean` очищает артефакты `./configure` (`Makefile`, `config.h`, `port.h`, `defs`,
  `rules`, `config.cache/log/status`), в git/пакет не попадают `.o/.a/.so`.
Возврат к онлайн-клонированию: `USE_BUNDLED=0 HYLAFAX_VERSION=master sudo ./install-astra.sh`
(осторожно: тега `v7.0.11` в ifax/HylaFAX не существует — используйте `master` или `HYLAFAX-6_0_7`).

### Новое в v1.3.0
- **Голосовые вызовы**: `voice-monitor.py` (systemd-юнит `fax-pdf-voice.service`) читает
  события RING / «UNANSWERED VOICE CALL» из syslog HylaFAX, складывает их в JSONL-очередь
  пропущенных/входящих звонков; на аппарате появляется режим **VOICE** (LCD мигает RING →
  трубка поднята). Кнопка **VOICE** — снять/положить «трубку», **STOP** — завершить разговор.
  Автоответ включается чекбоксом «Отвечать на голосовые» (+ число колец до ответа);
  параметры пишутся в `~/.config/fax-pdf/config.json` и синхронизируются с
  `RingsVoiceAnswer` в конфигах модема HylaFAX (`$SPOOL/etc/config.tty*`).
  Для реального голоса нужен модем с голосовой поддержкой (Class 1.0 voice); без неё
  вызов регистрируется и «отвечает» на уровне линии.
- **Клавиатура набора номера**: цифры 0–9, `*`, `#`, `+`, `C` (сброс), **REDIAL** — повтор
  последнего номера; набор напрямую на LCD аппарата перед отправкой.
- **Выбор файлов для отправки**: кнопка **TX▲** открывает диалог с множественным выбором
  PDF/TIFF — пачка отправляется последовательно (прогресс TX i/n на экране); во вкладке
  «Отправка» тоже можно указать несколько файлов через `;`.
- **Путь сохранения принятых факсов**: по умолчанию — домашняя папка пользователя
  (`/home/user`); меняется кнопкой **SAVE…** на аппарате или полем «Папка для принятых
  факсов» (Выбрать…/Открыть). Выбор сохраняется в `~/.config/fax-pdf/config.json` и
  `$SPOOL/etc/recv-archive.conf`, который учитывает серверный `recv-monitor.py`.

## Веб-интерфейс (опционально)
```bash
sudo apt install python3-flask
cd webapp && python3 app.py   # http://<ip>:8088 — загрузка PDF, очередь, журнал
```

## Удаление
`sudo ./uninstall.sh` — останавливает сервисы, удаляет пакеты; данные остаются.
